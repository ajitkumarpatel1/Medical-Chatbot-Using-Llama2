# Medical-Chatbot-Using-Llama2

### Creating new Environment
```bash
conda create -n mchatbot python=3.8 -y
```
### Activating the New Environment
```bash
conda activate mchatbot
```

### Dawnloding the requirements(Dependency) for Project
```bash
pip install -r requirements.txt
```

### Dawnlode The "llama-2-7b-chat.ggmlv3.q4_0.bin" Model from the following link: https://huggingface.co/TheBloke/Llama-2-7B-Chat-GGML/tree/main
