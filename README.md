# Medical-Chatbot-Using-Llama2

## Objective:

Welcome to the Medical-Chatbot-Using-Llama2 project repository! This project aims to develop an advanced medical chatbot utilizing natural language processing (NLP) techniques and information sourced from "The Gale Encyclopedia of Medicine" PDF file. The chatbot aims to provide accurate and reliable medical information to users.

## Features

- **NLP Integration:** Incorporates sophisticated natural language processing algorithms to understand and respond effectively to user queries related to various medical conditions, treatments, and health-related inquiries.
  
- **Knowledge Base:** Extracts and structures medical data from "The Gale Encyclopedia of Medicine" PDF file, offering categorized and updated information for the chatbot's database.

- **User Interaction:** Provides an interactive interface for seamless communication, offering personalized responses, suggesting medical advice, and delivering reliable information on symptoms, diagnoses, treatments, and preventive healthcare measures.


## Getting Started

To get started with the Medical-Chatbot-Using-Llama2 project, follow these steps:

1. ### Dawnlode The "llama-2-7b-chat.ggmlv3.q4_0.bin" Model from the following link: 
[Google](https://huggingface.co/TheBloke/Llama-2-7B-Chat-GGML/tree/main)

2. ### Dawnlode the Dataset from the following link:: 
[Google](https://www.academia.edu/34959665/Gale_Encyclopedia_of_Medicine)


3. **Clone the Repository:**
   ```bash
   git clone https://github.com/ajitkumarpatel1/Medical-Chatbot-Using-Llama2.git
   ```

4. **Creating new Environment:**
```bash
conda create -n mchatbot python=3.8 -y
```
5. **Activating the New Environment:**
```bash
conda activate mchatbot
```
6. **Dawnloding the requirements(Dependency) for Project:**
```bash
pip install -r requirements.txt
```
